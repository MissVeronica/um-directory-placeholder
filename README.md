# UM Directory Placeholder
Extension to Ultimate Member for replacing the Members Directory Search Placeholder with a Custom Placeholder.
## Settings -> UM Member Directories
* Edit a Member Directory
* Find the "Custom Search Placeholder" settings box -> Enter your Custom Search Placeholder for this Directory
## Installation and Updates
* Download and install the "Directory Placeholder" plugin ZIP file via the green "Code" button at this site
* Install as new Plugin, upload the "Directory Placeholder" ZIP file in WordPress -> Plugins -> Add New -> Upload Plugin.
* Activate the "Directory Placeholder" Plugin
