# UM Directory Search Placeholder
Extension to Ultimate Member for replacing the Members Directory Search Placeholder with a Custom Placeholder.
## Settings -> UM Member Directories
* Edit a Member Directory
* Find the "Custom Search Placeholder" settings box -> Enter your Custom Search Placeholder for this Directory
## Updates
* Version 1.1.0 - Added site language independence
## Installation and Updates
* Download and install the "Directory Search Placeholder" plugin ZIP file via the green "Code" button at this site
* Install as new Plugin, upload the "Directory Search Placeholder" ZIP file in WordPress -> Plugins -> Add New -> Upload Plugin.
* Activate the "Directory Search Placeholder" Plugin
